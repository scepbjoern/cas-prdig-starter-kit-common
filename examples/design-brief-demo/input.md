# Vorbereiteter Demoauftrag

Fiktives Unternehmen: Auenwerk. Im Einkauf werden Bestellanforderungen in einer bestehenden sachlichen ERP-Oberfläche geprüft. Eine Einkäuferin sieht Nummer, Lieferant, Betrag, Termin und Status. Für den Unterricht soll ein enger Ausschnitt realitätsnah aussehen, kein neues Marketingportal entstehen.

Die beigelegte synthetische Referenz zeigt eine typische kompakte Tabellenansicht. Drei fiktive Bestellungen genügen. Im späteren Prototyp wird eine Freigabe an ein Portal gemeldet; der konkrete Interface/Data Contract wird separat festgelegt.

Auftrag: Mit define-system-design einen schlanken Design Brief erarbeiten. Keine vollständigen Masken oder einzelnen Feldpositionen spezifizieren. Aussehen und Bedienverhalten sind hier besonders wichtig; die Schnittstelle wird für die spätere Integration verbindlich.

Vorbereitete Antworten für die Demo: kompakte Desktopansicht beibehalten; Blau/Grau wie in der Referenz; Status immer auch als Text; keine dunkle Variante; keine erfundenen zusätzlichen Funktionen.
