# Design-Brief-Demo für den Unterricht

Die Demo benötigt keinen fertigen studentischen Bericht. Sie zeigt an vorbereitetem Material, was ein Skill beiträgt und was Menschen entscheiden.

## Material

- input.md: kurzer Auftrag für eine fiktive Einkaufsfreigabe.
- reference.svg: synthetische ERP-Referenz, kein Screenshot eines echten SAP- oder Unternehmenssystems.
- design-brief.md: ausgearbeitetes Ergebnisbeispiel.
- demo-script.md: Ablauf mit wenigen gezielten Rückfragen.

Im System-Kit define-system-design mit diesen Eingaben verwenden. Die mitgelieferte Referenz ist nur Demo-Material und wird durch Bootstrap niemals in studentische Projekte kopiert.
Der erste technische Demonstrator wird separat aus dem System-Kit aufgebaut. Design-Skill, technische Laufprüfung und menschliche Abnahme sind unterschiedliche Nachweise. VALIDATION.md beschreibt die tatsächlich ausgeführte Erprobung.

## Geprüfter Demonstrator

[Desktopansicht](design-demo-desktop.png) und [schmale Ansicht](design-demo-mobile.png) zeigen den separat aufgebauten Stand. demonstrator/ enthält ausschliesslich die zusätzlichen Demo-Dateien für ein bereits aufgebautes Webprofil; keine automatische Installation in studentische Projekte. Für die Vorführung den neutralen Bootstrap ausführen, diese Demo-Dateien bewusst übernehmen und die zwei mitgelieferten Browserprüfungen ausführen. Ohne laufenden Server können die Bilder und der Design Brief verwendet werden.
