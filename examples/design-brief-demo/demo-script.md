# Kurze Skill-Demo

1. Auftrag und synthetische Referenz zeigen. «Ein Skill bringt eine vorbereitete Arbeitsweise mit; der Agent führt sie aus.»
2. Im System-Projekt: «Nutze define-system-design für diesen kurzen Kontext und diese Referenz.»
3. Erwartetes Verhalten: vorhandene Muster erkennen, wenige echte Fragen stellen. Beispiel: kompakte Bestandssicht beibehalten oder bewusst modernisieren? Welche Dimension der Realitätsnähe ist zentral?
4. Die vorbereiteten Antworten aus input.md geben. Der Agent erstellt einen knappen Design Brief; er verlangt nicht alle Masken und Felder.
5. Ergebnis in MarkText lesen, einen Grundsatz von Hand präzisieren und den Agenten die Auswirkungen prüfen lassen.
6. Zeigen, wie PRD, System Architecture und Feature Plan später darauf verweisen. Ein anderer Implementierungsagent nutzt diese Quellen.

Fachlicher Lernpunkt: Die Studierenden entscheiden über die passende Gestaltung und prüfen das Ergebnis. Der Skill strukturiert die Zusammenarbeit; er ersetzt ihre Entscheidungen nicht.
